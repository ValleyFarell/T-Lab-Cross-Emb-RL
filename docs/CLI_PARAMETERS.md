# Справочник параметров всех команд

Названия параметров оставлены без изменения: именно их ожидает код. Пояснения описывают смысл, а не предлагают менять алгоритмы. Все команды запускаются из корня проекта; точные актуальные значения по умолчанию можно посмотреть через `python -m scripts.ИМЯ_СКРИПТА --help`.

## Общие параметры эпизода

| Параметр | Что задаёт |
| --- | --- |
| `--checkpoint` | Каталог замороженного агента с `params.pkl` и `flags.json`. |
| `--task-id` | Номер одной официальной задачи OGBench. |
| `--task-ids` | Список номеров задач для одного группового запуска. |
| `--tasks` | Список задач в `evaluate_baseline`. |
| `--start-xy X Y` | Центр свободной клетки, из которой начинается собственный сценарий. |
| `--goal-xy X Y` | Центр свободной клетки, являющейся целью собственного сценария. |
| `--environment-seed` | Число, определяющее воспроизводимое начальное состояние среды. |
| `--controller-seed` | Число, определяющее воспроизводимую случайность контроллера. |
| `--seeds` | Список инициализаций среды для серии экспериментов. |
| `--temperature` | Случайность выбора действий; ноль означает детерминированный режим. |
| `--controller` | Тип высокоуровневого контроллера в общем запуске. |
| `--results-dir` | Каталог сохранения эпизодов. |
| `--log-file` | Файл журнала с параметрами группового запуска. |
| `--device` | Устройство вычислений: `cpu`, `gpu` или `auto`, если скрипт поддерживает эти варианты. |

`--task-id` нельзя задавать одновременно с `--start-xy` и `--goal-xy`. Собственные координаты всегда задаются парой.

## H0 и H0-B

| Параметр | Объяснение |
| --- | --- |
| `--max-candidates` | Максимальное количество промежуточных состояний; для H0 число пар растёт квадратично. |
| `--pair-batch-size` | Максимальное количество пар в одном обращении к прямому представлению. |
| `--eta-epsilon` | Минимальный допустимый модуль знаменателя коэффициента достижимости `η`. |
| `--h0-replan-interval` | Число шагов между повторным построением плана. |

## Локальный H0 и финиш

| Параметр | Объяснение |
| --- | --- |
| `--candidates-per-cell` | Сколько офлайн-состояний можно взять из одной клетки лабиринта. |
| `--grid-cell-size` | Размер клетки пространственной сетки в координатах карты. |
| `--local-radius` | Радиус вокруг робота, в котором разрешена первая исполняемая подцель. |
| `--max-local-candidates` | Верхняя граница числа локальных первых подцелей. |
| `--finish-radius` | Расстояние до цели, на котором включается отдельный режим финиша. |
| `--finish-mode` | Способ управления у цели; допустимые значения зависят от конкретного скрипта. |
| `--direct-latent-mode` | `raw` оставляет целевой вектор без изменений, `normalized` нормализует его. |
| `--switch-margin` | Минимальное улучшение, необходимое для выбора маршрута с переключением. |
| `--no-zero-level` | Отключает сравнение с прямым вариантом без промежуточных целей. |
| `--no-finish-latch` | Отключает фиксацию финишного режима после первого входа в его область. |
| `--help-local` | Показывает только дополнительные параметры локального H0. |

## Выбор состояния около цели: H-goal-EuR

| Параметр | Объяснение |
| --- | --- |
| `--variant` | `synthetic-current` создаёт синтетическое целевое состояние; `dataset-max-v` выбирает реальное офлайн-состояние. |
| `--hge-replan-interval` | Число шагов между повторным выбором состояния цели. |
| `--hge-candidate-radius` | Радиус поиска реальных состояний вокруг координат цели. |
| `--hge-max-candidates` | Максимальное число кандидатов около цели. |
| `--hge-disagreement-penalty` | Штраф за расхождение оценщиков замороженного ансамбля. |

## Проекция декодированной подцели

| Параметр | Объяснение |
| --- | --- |
| `--decoder` | Каталог с обученным декодером намерения либо путь к `decoder.npz`. |
| `--candidate-radius` | Радиус поиска реальных офлайн-состояний вокруг декодированной точки. |
| `--max-candidates` | Максимальное число состояний для сравнения. |
| `--disagreement-penalty` | Штраф за расхождение участников FB-ансамбля. |
| `--selection-mode` | `max-v` выбирает по ценности; `nearest-xy` — по близости координат. |
| `--finish-mode` | `task-latent` фиксирует исходную задачу; `fixed-v-max` выбирает целевое состояние один раз; `dynamic-v-max` перевыбирает его при перепланировании. |
| `--replan-interval` | Число шагов между повторной проекцией подцели. |

## Динамический планировщик трёх точек

| Параметр | Объяснение |
| --- | --- |
| `--model-dir` | Каталог с четырёхмерной моделью геометрии и декодером намерений. |
| `--compare-baseline` | Дополнительно запускает исходный агент на тех же сценариях. |
| `--intention-mode` | `decoded`, `exact-b` или `both`: обученный декодер, прямое `B(w)` либо оба варианта. |
| `--max-states` | Максимальное число офлайн-состояний, доступных планировщику. |
| `--max-candidates` | Максимальное число промежуточных точек после построения набора кандидатов. |
| `--grid-resolution` | Число делений каждой оси вспомогательной четырёхмерной сетки. |
| `--disable-grid` | Оставляет только реальные офлайн-точки, отключая дополнительные точки сетки. |
| `--rerank-count` | Число лучших предварительных вариантов, перепроверяемых исходным FB-критиком. |
| `--fb-batch-size` | Максимальный размер блока обращений к замороженному FB-ансамблю. |
| `--replan-interval` | Число шагов между плановыми перестроениями маршрута. |
| `--finish-radius` | Расстояние до цели, на котором маршрут заменяется финишным управлением. |
| `--finish-mode` | `baseline` использует исходный контроллер, `task-latent` — целевое намерение напрямую. |
| `--fallback-mode` | Управление, которое применяется, когда подходящий маршрут не найден. |
| `--eta-epsilon` | Защита от почти нулевого знаменателя при вычислении `η`. |
| `--minimum-eta` | Минимальная допустимая достижимость каждого перехода. |
| `--min-improvement` | Минимальное улучшение оценки маршрута относительно прямого варианта. |
| `--disagreement-penalty` | Штраф за расхождение участников FB-ансамбля. |
| `--support-multiplier` | Допустимое удаление искусственной точки от области существующих офлайн-данных. |
| `--waypoint-replan-radius` | Радиус, в котором текущая промежуточная точка считается достигнутой. |
| `--disable-arrival-replan` | Отключает внеплановое перепланирование при достижении первой точки. |

## Обучение четырёхмерной геометрии

| Параметр | Объяснение |
| --- | --- |
| `--output-dir` | Каталог сохранения моделей, оценок и промежуточных данных. |
| `--geometry-model` | Уже обученная совместимая модель геометрии, которую не нужно обучать заново. |
| `--cache` | Ранее сохранённые значения замороженного критика для обучающих пар. |
| `--force-recompute` | Принудительно пересчитывает сохранённые оценки критика. |
| `--max-states` | Верхняя граница числа используемых офлайн-состояний. |
| `--train-pairs` | Число обучающих пар «начальное состояние — цель». |
| `--goal-count` | Число различных целевых состояний. |
| `--teacher-batch-size` | Размер блока запросов к замороженному FB-критику. |
| `--hidden-dim` | Ширина скрытых слоёв модели геометрии. |
| `--decoder-hidden-dim` | Ширина скрытых слоёв декодера намерений. |
| `--epochs` | Максимальное число проходов обучения модели геометрии. |
| `--decoder-epochs` | Максимальное число проходов обучения декодера. |
| `--batch-size` | Число примеров в одном шаге обучения. |
| `--learning-rate` | Размер шага обновления параметров. |
| `--patience` | Сколько проходов ждать улучшения до ранней остановки. |
| `--validation-fraction` | Доля данных, отложенная для проверки во время обучения. |
| `--block-size` | Размер соседних временных блоков при разделении данных. |
| `--seed` | Воспроизводимая инициализация обучения и разбиения данных. |

| `--max-epochs` | Максимальное число проходов по обучающим данным. |
| `--patience` | Число проходов без улучшения до остановки. |
| `--weight-decay` | Сила регуляризации весов. |

| `--gradient-clip-norm` | Верхняя граница нормы градиента. |
| `--target-rmse` | Желаемая среднеквадратичная ошибка одной координаты. |

## Геометрия FB-ценности

| Параметр | Объяснение |
| --- | --- |
| `--target-mode` | `xy-goal`, `state-goal` или `fixed-task`: пространственная цель, полное состояние либо фиксированная задача. |
| `--task-id` | Номер официальной задачи при `--target-mode fixed-task`. |
| `--model-seeds` | Независимые начальные инициализации вспомогательных моделей. |
| `--models` | Список сравниваемых архитектур: `xy`, `full`, `pose`, `latent2`, `latent4` и другие. |
| `--goal-variants` | Число разных полных состояний возле близких координат цели. |
| `--pose-radius` | Радиус, в котором целевые положения считаются пространственно близкими. |
| `--candidates-per-start` | Число целевых состояний для одного начального состояния. |
| `--reference-samples` | Число состояний для построения представления конечной награды. |
| `--distance-mode` | `maze`, `euclidean` или `auto`: расстояние по коридорам, по прямой либо автоматический выбор. |
| `--distance-bins` | Число диапазонов расстояния для отдельного анализа. |
| `--hidden-width` | Ширина скрытых слоёв вспомогательной модели. |
| `--hidden-layers` | Число скрытых слоёв. |
| `--weight-decay` | Сила регуляризации весов. |
| `--gradient-clip` | Верхняя граница нормы градиента. |
| `--log-every` | Как часто печатать ход обучения. |
| `--quick` | Уменьшает число состояний, целей, пар и проходов обучения. |
| `--synthetic` | Проверяет конвейер на искусственных данных без настоящего чекпоинта. |
| `--synthetic-states` | Количество искусственных состояний. |
| `--resume` | Переиспользует сохранённый `pair_cache.npz`. |
| `--no-plots` | Отключает сохранение графиков. |

Параметры `--max-states`, `--train-pairs`, `--goal-count`, `--teacher-batch-size`, `--batch-size`, `--epochs`, `--patience` и `--learning-rate` имеют тот же смысл, что и при обучении четырёхмерной геометрии.

## Поправки на начальное и целевое состояние

| Параметр | Объяснение |
| --- | --- |
| `--data-dir` | Существующий каталог с парами состояний и оценками критика. |
| `--inspect-cache` | Выводит названия и размеры сохранённых массивов и завершает работу. |
| `--models` | Архитектуры: `xy`, `xy_start`, `xy_goal`, `xy_both`, `xy_additive`, `full`. |
| `--critic-batch-size` | Размер блока запросов к замороженному критику. |
| `--hidden-dim` | Ширина основной модели ценности. |
| `--quality-hidden-dim` | Ширина сетей, оценивающих качество состояния. |
| `--gate-regularization` | Сила ограничения поправочных коэффициентов. |

Остальные параметры обучения совпадают со справочником выше.

## Визуализация и диагностика финиша

| Параметр | Объяснение |
| --- | --- |
| `--trajectory` | Путь к сохранённому файлу `trajectory.npz`. |
| `--env-name` | Имя используемой среды OGBench. |
| `--goal` | Дополнительное явное указание цели для проверки ориентации карты. |
| `--out` / `--output` | Путь к сохраняемому изображению или итоговому JSON-файлу. |
| `--dataset` | Часть офлайн-набора: `train` либо `validation`. |
| `--dataset-index` | Точный индекс состояния; без него состояние выбирается по `--seed`. |
| `--step-size` | Как часто рисовать намерения вдоль траектории. |
| `--show` | Дополнительно открывает окно графика после сохранения. |
| `--source-results` | Каталог ранее сохранённых эпизодов для проверки поведения у цели. |
| `--entry-radius` | Радиус, в котором выбирается начальное состояние продолжения. |
| `--success-radius` | Радиус, считающийся успешным достижением цели. |
| `--horizon` | Максимальное число шагов каждого продолжения. |
| `--goal-state-count` | Число разных реальных состояний в окрестности цели. |
| `--goal-state-seed` | Случайная инициализация выбора этих целевых состояний. |
| `--max-source-runs` | Ограничение числа исходных эпизодов для быстрой проверки. |

# Обучение исходных агентов официального проекта

## Когда это нужно

Для основного задания T-Lab переобучать исходный агент не требуется: готовый чекпоинт уже находится в репозитории, а `F`, `B` и политики должны оставаться замороженными. Этот документ нужен только для воспроизведения исходных экспериментов официального проекта или отдельного исследования обучения.

## Общая команда

```bash
python main.py \
  --env_name=ogbench-antmaze-medium-navigate-v0 \
  --agent=agents/fbpiswitch.py \
  --seed=0 \
  --enable_wandb=0
```

| Параметр | Что означает |
| --- | --- |
| `--env_name` | Название среды и размера лабиринта. |
| `--agent` | Python-файл с реализацией и настройками агента. |
| `--seed` | Воспроизводимая инициализация обучения. |
| `--enable_wandb` | `1` включает внешний журнал Weights & Biases; `0` отключает его. |
| `--train_steps` | Общее число обновлений параметров. |
| `--agent.discount` | Коэффициент дисконтирования будущей награды. |
| `--agent.alpha` | Вес или температурный коэффициент конкретного алгоритма. |
| `--agent.high_alpha` | Коэффициент высокоуровневой политики. |
| `--agent.orthonorm_coeff` | Сила регуляризации ортонормальности представления. |
| `--agent.frozen_path` | Путь к уже обученным представлениям, которые требуется заморозить. |

По умолчанию `main.py` выполняет 1 000 000 шагов обучения, проверяет агента каждые 100 000 шагов и с той же периодичностью сохраняет чекпоинты.

## Доступные агенты

| Файл | Смысл |
| --- | --- |
| `agents/icvf.py` | Функция ценности, зависящая от намерения. |
| `agents/onestep_fb.py` | Одношаговое обучение FB-представлений. |
| `agents/hiql.py` | Иерархическое обучение политики и функции ценности. |
| `agents/hiql_nonhierarchical.py` | Вариант без отдельной высокоуровневой политики. |
| `agents/hiql_bilinear.py` | Вариант с билинейной оценкой ценности. |
| `agents/hiql_intentions.py` | Вариант с явными намерениями. |
| `agents/fb.py` | Обучение прямого и обратного представлений. |
| `agents/fb_hierarchical.py` | Высокоуровневая политика поверх заранее обученных FB-представлений. |
| `agents/fbpiswitch_nonhierarchical.py` | Обучение представлений и низкоуровневой политики FB π-Switch. |
| `agents/fbpiswitch.py` | Высокоуровневая политика переключения поверх замороженной модели. |

## Примеры

Обучение обычных FB-представлений:

```bash
python main.py \
  --env_name=ogbench-antmaze-medium-navigate-v0 \
  --agent=agents/fb.py \
  --seed=0 \
  --enable_wandb=0
```

Неиерархическое обучение FB π-Switch:

```bash
python main.py \
  --env_name=ogbench-antmaze-medium-navigate-v0 \
  --agent=agents/fbpiswitch_nonhierarchical.py \
  --agent.orthonorm_coeff=0.0001 \
  --seed=0
```

Обучение высокоуровневой политики поверх уже готовых представлений:

```bash
python main.py \
  --env_name=ogbench-antmaze-medium-navigate-v0 \
  --agent=agents/fbpiswitch.py \
  --train_steps=500000 \
  --agent.frozen_path=ПУТЬ_К_ГОТОВЫМ_ПРЕДСТАВЛЕНИЯМ \
  --seed=0
```

Для большого лабиринта замените имя среды на `ogbench-antmaze-large-navigate-v0`, для гигантского — на `ogbench-antmaze-giant-navigate-v0`; для длинных задач исходные конфигурации часто используют `--agent.discount=0.995`.

## Восстановление и сохранение

- `--restore_path` задаёт путь к ранее сохранённому агенту.
- `--restore_epoch` выбирает шаг восстанавливаемого чекпоинта.
- `--save_dir` определяет корневой каталог экспериментов.
- `--wandb_run_group` объединяет внешние записи в именованную группу.
- `--eval_episodes` задаёт число проверочных эпизодов.
- `--video_episodes` определяет количество записываемых видео.
- `--video_frame_skip` задаёт шаг пропуска кадров.

Результаты переобучения нельзя смешивать с основным сравнением методов, работающих поверх неизменного предоставленного чекпоинта: это другая экспериментальная постановка.

# H0: две промежуточные цели

## Интуиция

H0 оценивает не только ближайшую подцель, но и то, можно ли после неё продолжить путь через вторую точку. Обе точки берутся из уже имеющегося офлайн-набора. После выбора маршрута реально исполняется только первая команда; следующий маршрут строится по новому наблюдению.

## Мотивация

В лабиринте полезная первая подцель может находиться не по прямой к цели, а возле поворота. Вторая точка помогает понять, откроет ли этот поворот хорошее продолжение. Новые данные среды для обучения не собираются, а параметры `F`, `B` и политик не изменяются.

## Математика в трёх предложениях

Для каждого состояния `wᵢ` строится `zᵢ = normalize(B(wᵢ))`, а `Vᵢ(s) ≈ ⟨F(s,zᵢ),z_r⟩`. Пара оценивается как `J₂ = V₁(s) + η₁[V₂(w₁)-V₁(w₁)] + η₁η₂[V_g(w₂)-V₂(w₂)]`. Выбирается лучшая допустимая пара, а низкоуровневой политике передаётся только `z₁`.

## Подробная формула

$$
J_2(s,w_1,w_2)
=V_1(s)
+\eta_1[V_2(w_1)-V_1(w_1)]
+\eta_1\eta_2[V_g(w_2)-V_2(w_2)].
$$

Коэффициенты приближённо вычисляются как

$$
\eta_1\approx
\frac{\langle F(s,z_1),z_1\rangle}
{\langle F(w_1,z_1),z_1\rangle},
\qquad
\eta_2\approx
\frac{\langle F(w_1,z_2),z_2\rangle}
{\langle F(w_2,z_2),z_2\rangle}.
$$

Все величины `V` оценивают одну и ту же конечную задачу. Отношения ограничиваются диапазоном `[0,1]`; почти нулевые знаменатели делают кандидата недопустимым.

## Запуск

```powershell
python -m scripts.run_h0 `
  --task-id 1 `
  --environment-seed 0 `
  --controller-seed 0 `
  --temperature 0 `
  --max-candidates 64 `
  --pair-batch-size 4096 `
  --eta-epsilon 0.000001 `
  --h0-replan-interval 1 `
  --results-dir results_h0
```

| Параметр | Значение |
| --- | --- |
| `--task-id` | Номер официальной задачи. |
| `--environment-seed` | Случайная инициализация среды. |
| `--controller-seed` | Случайная инициализация контроллера. |
| `--temperature` | Степень случайности действия. |
| `--max-candidates 64` | До 64 состояний, то есть до 4096 пар. |
| `--pair-batch-size` | Число пар в одном вычислительном блоке. |
| `--eta-epsilon` | Минимальный допустимый модуль знаменателя. |
| `--h0-replan-interval 1` | Перепланирование после каждого шага. |
| `--results-dir` | Каталог результатов. |

Альтернативная команда: `python -m scripts.run_baseline --controller h0 --task-id 1`. Для собственных координат вместо номера задачи используйте `--start-xy 0 0 --goal-xy 4 4`; карту смотрите в README.

## Производительность и диагностика

При 64 кандидатах оцениваются 4096 пар; при 32 — 1024. Представления отдельных состояний вычисляются заранее, а зависящее от обоих кандидатов значение `F(w₁,z₂)` считается блоками.

В `config.json` сохраняются индексы и контрольная сумма кандидатов, число пар и настройки численной защиты. В `trajectory.npz` записываются оценка маршрута, выбранные индексы, коэффициенты `η`, число недопустимых значений и признаки перепланирования.

Реализация: `hypotheses/h0/planner.py`, `controllers/two_switch.py`, `scripts/run_h0.py`.

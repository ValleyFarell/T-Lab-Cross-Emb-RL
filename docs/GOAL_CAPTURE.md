# Диагностика петель около цели

## Интуиция

Иногда робот почти дошёл до нужной точки, но вместо попадания в радиус успеха начинает двигаться по окружности. Чтобы понять причину, скрипт берёт уже сохранённое физическое состояние возле цели и несколько раз продолжает движение с разными намерениями, не меняя стартовую позу и скорость.

## Мотивация

Если одна и та же поза приводит к разным результатам при разных целевых намерениях, проблема может находиться в представлении цели. Если не справляются все намерения, вероятнее ограничение низкоуровневой политики или самой физической динамики.

## Математика в трёх предложениях

Выбирается первое сохранённое состояние с расстоянием `r_success < ||xy(s)-g|| < r_entry`. Для одного и того же полного физического состояния запускаются продолжения под исходным целевым вектором, его нормализованной версией и намерениями `normalize(B(w_g))` реальных офлайн-состояний возле цели. Затем сравниваются попадание в целевой радиус, минимальное расстояние, радиальная и касательная скорости.

## Запуск

```powershell
python -m scripts.diagnose_goal_capture `
  --source-results results_baseline `
  --goal-xy 4 4 `
  --entry-radius 1.0 `
  --success-radius 0.5 `
  --goal-state-count 8 `
  --horizon 100 `
  --temperature 0 `
  --output-dir results_goal_capture
```

| Параметр | Значение |
| --- | --- |
| `--source-results` | Каталог ранее сохранённых траекторий. |
| `--goal-xy` | Цель исходного эксперимента; координаты обязаны совпадать. |
| `--entry-radius` | Радиус выбора состояния для продолжения. |
| `--success-radius` | Радиус, считающийся успешным попаданием. |
| `--goal-state-count` | Число разных реальных состояний около цели. |
| `--horizon` | Максимальное число шагов каждого продолжения. |
| `--temperature` | Случайность низкоуровневой политики. |
| `--output-dir` | Каталог результатов диагностики. |

Для короткой проверки добавьте `--max-source-runs 2 --goal-state-count 3 --horizon 50`.

## Результаты

`branches.csv` содержит отдельные продолжения, `aggregate.csv` и `aggregate.json` — сводки, а подкаталог `branches/` хранит траектории каждого варианта.

| Поле | Смысл |
| --- | --- |
| `hit_rate` | Доля продолжений, попавших в радиус успеха. |
| `minimum_distance` | Минимальное расстояние до цели. |
| `mean_radial_velocity` | Скорость движения к центру цели. |
| `mean_tangential_speed` | Скорость движения вдоль окружности. |
| `radius_exits` | Количество выходов обратно за внешний радиус. |
| `fell_below_0_3` | Признак физического падения робота. |

Если реальные целевые состояния дают лучший результат, причиной может быть выбор полного целевого состояния. Если все варианты петляют, вероятнее ограничение низкоуровневого управления. Разные продолжения одной физической точки нельзя считать независимыми инициализациями среды.
